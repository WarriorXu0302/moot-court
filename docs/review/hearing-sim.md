# 庭审 AI 发言打磨记录（2026-11）

## 方法

`scripts/hearing-sim.ts` 用真实大模型整场跑庭审：AI 扮演学生，其他角色的提示词与页面完全相同（都来自 `src/lib/hearing-engine.ts`）。跑完后做两层检查：

- **规则检查**：角色越位（当事人安排程序）、中英混杂、括号动作、占位符、篇幅、主持人提前表态、一次发言连问多个问题等。
- **AI 审阅**：以法官兼模拟法庭教练的视角逐句审阅，分为程序错误、事实编造、法律错误、泄露结论、语言风格、回应失焦等类别。

```bash
pnpm exec tsx scripts/hearing-sim.ts --case=天卓 --role=prosecutor --phase=both --out=/var/tmp/hearing-sim/x
pnpm exec tsx scripts/hearing-sim.ts --rereview=/var/tmp/hearing-sim/x   # 用当前审阅标准重审已有笔录
```

## 结果（天卓案、恒基案 × 三个角色 × 调查、辩论，各 14 场；用同一审阅标准重审后比较）

| 轮次 | AI 发言 | 问题 / 条 | 高严重度 / 条 |
|---|---|---|---|
| 基线 | 164 | 0.67 | 0.024 |
| 第二轮 | 266 | 0.35 | 0.015 |
| 第三轮 | 240 | 0.37 | 0.013 |
| 第四轮（问题最多的 4 场复跑） | 105 | 0.44（这 4 场基线为 0.63） | 0 |
| 第五轮（加入庭审设定，恒基案改为诉讼） | 107 | 0.36 | 0.019 |
| 第六轮（缺席当事人、收尾分两步） | 112 | 0.24 | 0.009 |
| 第八轮（证人知情途径、去掉"以……为准"） | 110 | 0.19 | 0 |

第五轮起均为同样 4 场：天卓案原告调查、天卓案审判长调查、恒基案被告调查、恒基案审判长辩论。

AI 发言条数变多，是因为补齐了程序环节，并把证人询问改成了多轮一问一答。

## 改了什么

- **程序环节补齐**（`flows/civil.ts`、`flows/arbitration.ts`）：书记员（仲裁秘书）查明到庭并宣读纪律；双方确认身份与回避；双方对争议焦点表态；证人、专家出庭前的身份核实与如实作证告知；被申请人举证后的质证；第二轮辩论由审判长主持；征询最后意见；询问调解意愿。
- **一问一答**：AI 询问证人、专家最多 3 轮，每轮一问；学生发问的环节可以连续追问 3 次。
- **每个环节的要点清单**（`hearing-engine.ts` 的 `STAGE_GUIDES`）：写明这一步按真实庭审应包含什么。例如开庭要宣布案由、合议庭组成、权利义务和回避；举证要说证明目的；质证要按三性逐项表态。
- **主持权**：只有审判长、首席仲裁员能安排程序。主持人回应他人时，也会被告知下一环节是谁，避免跳过环节。
- **回应方式**：证人只按笔录回答，笔录里没有的说"不清楚"，不编造细节；主持人对程序请求当场作出处理，不只说"已记录"。
- **笔录形式**：不用加粗和列表，按当庭口头表达写；不说"模拟""材料节选"这类出戏的话。
- 学生发言后，下一环节如果本来就由对方发言，不再让对方先回应一次，避免同一人连说两段。

- **庭审设定**（`meta.hearingSetup`，`scripts/enrich-hearing.ts` 为 57 个教材案例生成，教师端审核面板可见，列为 AI 拟制）：双方代理权限与授权事项、未委托代理人到庭的当事人（按缺席处理）、证人的任职与知情范围（每条事实注明知情途径，另列不知道的事项）、专家背景与出庭依据。学生卷宗新增「授权委托书」分区，证人与专家的出庭说明并入「证人与专家陈述」；证人"不知道的事项"只给 AI，不给学生。
- **恒基案改为涉外民商事诉讼**（法院审查仲裁协议效力）。其余六个"仲裁"案例保持不变。
- **调查收尾分两步**：主持人先问有无新证据或补充，双方答复后再宣布调查结束，不在同一句话里问完就结束。
- **询问的结束**：同一次发言里既提问又说"询问完毕"的，自动去掉"询问完毕"，等对方回答。
- **主持人不连说两段**：学生发言后若下一环节本就由主持人进行，不再单独回一句"本庭已记录"。
- **不置可否的套话**：去掉"以提交法庭的材料为准""未载明"等说法；身份证明、委托书视为已提交；不在每次发言结尾重复整套请求。

## 尚未解决

- **法律论证深度**：外国法查明专家被追问具体条文、判例时多答检索方向；代理人被追问管辖连结点时，有时只复述"应当审查"。这取决于案例资料里的法律依据是否充分，提示词能改善的空间有限。
- **审阅本身的口径**：同一类表述（如证据载体、证人记忆）在不同轮次分别被判为"编造"和"回避"，单次结果有 ±0.05 左右的波动，比较时要看多轮趋势。
